# Research Digest: Agent-Architecture Sources

Synthesized from a private reading collection of 23 unique papers, organized by theme rather than by paper. This is the source material behind *Director-Actor System Architecture.md*.

## 1. Cognitive architectures for character agents

**Laird & van Lent, "Human-Level AI's Killer Application: Interactive Computer Games"; Swartout et al., "Toward Virtual Humans" (TacAirSoar/MRE lineage).** Both use Soar as a shared-blackboard production-rule architecture: working memory holds beliefs/goals/task state, and independent modules (dialogue, emotion, perception) read/write to it rather than passing messages point-to-point, letting capabilities integrate without a fixed top-down design. Soar's Quakebot projects "what would I do if I were the human player" using the bot's own decision rules to anticipate enemy action — a reusable pattern for an Actor modeling other Actors' likely behavior. The MRE virtual humans add a tripartite task representation (causal history, current world state, hierarchical future task tree) shared across components, plus authority/responsibility role-tagging per task step — useful for an Actor's "what am I allowed to do without Director sign-off" logic.

## 2. Drama management / director-style oversight

**Aylett, "Narrative in Virtual Environments — Towards Emergent Narrative"; Brenner, "Creating Dynamic Story Plots with Continual Multiagent Planning."** Aylett inverts the standard plot-down hierarchy: narrative emerges bottom-up from simple drive-based agents, with a "social presence" mechanism nudging coherence without scripting — a lighter-touch alternative to heavy direction. Brenner's continual multiagent planning is more director-like: agents plan individually, but an action only enters another agent's plan if that agent's own commitment-precondition is satisfied, so the system supports non-benevolent agents and genuine conflict; the "plot" becomes a causally-annotated execution history recomputed as agents replan, rather than a single authored plan.

## 3. Character believability, personality, goals/intentions

**Riedl & Young, "An Objective Character Believability Evaluation Procedure" (Fabulist/IPOCL); Bates, "The Role of Emotion in Believable Agents" (Oz/Woggles); Umarov, Mozgovoy & Rogers, "Believable and Effective AI Agents in Virtual Worlds."** Riedl's IPOCL planner decouples character intentions from the author's story-outcome goal — it searches for plausible motivations and inserts motivating events explaining *why* a character acted, validated against readers' comprehension of "why" questions. Bates separates goal-directed behavior from a distinct emotional-appraisal module, with the design rule that emotional state must be visible and slightly exaggerated (subtlety reads as inert), plus a "quirk" principle: small idiosyncratic imperfections sell aliveness more than correctness does. Umarov et al. argue effectiveness and believability are often in tension (optimal play feels less human) and propose selecting among multiple competing behavioral strategies per turn rather than one "correct" response.

## 4. Social simulation and relationship modeling

**McCoy et al., "Prom Week: Social Physics as Gameplay" and "Comme il Faut: A System for Authoring Playable Social Models" (CiF).** CiF represents social state via five structures: binary public Relationships, scalar private Social Networks (per-dyad axes like Buddy/Romance/Cool), binary Statuses, permanent Traits, and a public Social Fact Database. Runtime loop: Desire Formation (every character scores volition to initiate each "social game" by summing weighted influence rules) → Intent Selection → Social Exchange (responder accepts/rejects via their own rule weight) → Social Fall-Out (cascading derived state changes) → Performance Realization. Reusable rule bundles ("microtheories") are shared across many exchange types — Prom Week shipped ~4,900 rules / ~100 microtheories across 18 characters. A strong template for a Director-owned social-state table.

## 5. Generative/LLM-based agents with memory, reflection, planning

**Park et al., "Generative Agents: Interactive Simulacra of Human Behavior" (UIST 2023); Stanford HAI, "Generative Agent Simulations of 1,000 People."** Core mechanism: a memory stream logs every observation as a timestamped natural-language entry; retrieval scores each memory by recency (exponential decay, factor 0.995), importance (LLM-rated 1–10 "poignancy" once at creation), and relevance (embedding cosine similarity to the current query), then sums/normalizes to select what enters the prompt. Reflection triggers when summed importance crosses a threshold (150): the LLM generates self-directed questions, retrieves supporting evidence, and synthesizes higher-level insights stored back into the stream with citations — forming a reflection tree (observations → mid-level reflections → higher abstractions). Planning is top-down then recursive: a coarse day-plan is decomposed into time-blocked entries, themselves stored in and retrieved from the same memory stream. The Stanford follow-up validates persona fidelity by seeding agents with full interview transcripts and checking agreement against the real person's later responses (85% as accurate as people matching their own future answers) — a usable technique for validating an Actor persona against the world bible.

## 6. Dialogue generation / NLP-specific techniques

**Callison-Burch et al., "Dungeons and Dragons as a Dialog Challenge for AI" (EMNLP 2022); Freiknecht & Effelsberg, "Procedural Generation of Interactive Stories using Language Models."** The D&D paper fine-tunes a single model for joint state-tracking and response generation, both conditioned on control features (player ID, in-character/out-of-character flag, character name/class/race/pronouns, combat status); the DM is auto-identified as the entity that can speak for multiple NPCs at once and is stripped of character labels — a near-exact blueprint for tagging Director vs. Actor turns. Freiknecht & Effelsberg combine a GPT-2-style generator with explicit state management (NER + WordNet noun restriction, coreference resolution capping named-character count) and compare three generation strategies — rule-based templates (controlled but repetitive), masked-LM infilling (best control/diversity balance), raw continuation (diverse but drifts) — plus sentiment-steered mood arcs via control words, useful for tuning an Actor's expressive range against drift risk.

## 7. Other load-bearing mechanisms

**Zubek & Khoo, "Making the Human Care"; Hausknecht et al., "Interactive Fiction Games: A Colossal Adventure"; Miyashita et al. on RL+SL blending; Kerr/Cohen/Adams activity-recognition (CAVE).** Zubek & Khoo's bots maintain a per-player valence memory (a running scalar of how the bot "feels" toward each human) that modifies dialogue choice — a cheap way for an Actor to track sentiment toward another character without full relationship modeling. Hausknecht's Jericho/DRRN treats interactive fiction as a POMDP solved by encoding observation and each candidate action separately to estimate joint Q-values — relevant if Actors should select among a constrained action menu rather than free-generate. Kerr et al.'s CAVE algorithm infers hidden internal state (goals, emotional arousal) from only observable behavior via signature alignment — a possible mechanism for the Director to infer an Actor's "true state" from its output alone.
